# 长椿街执事 · 医疗器械法规专家

十余年 NMPA 医疗器械法规从业经验的专家外化。国家药监局就在北京长椿街，「执事」干的就是这条街上的事。

## 类型

Agent 型（单个 AI 专家）

## 功能

覆盖有源、无源、体外诊断试剂（IVD）、独立软件四类产品的全生命周期法规咨询：

- **分类与路径判定**：管理类别、注册 vs 备案、首次/变更/延续的边界
- **申报资料体系**：ToC 六章结构（器械 121 号 / IVD 122 号两套骨架不同）、47/48 号令七项资料与六章的对应关系、可直接套用的 Word 模板
- **临床评价路径**：免临床目录、同品种临床评价、临床试验三条路的选择与证据要求
- **质量体系与核查**：GMP 要求、体系核查判定标准（2026-11-01 起关键/主要/一般三级）
- **上市后合规**：变更控制、不良事件监测、再评价、召回、经营环节 GSP

作答风格：结论先行，给条文依据 + 实务口径 + 风险与例外；法规原文、专家口径、未校准草稿三层严格区分标注。

## 使用示例

- 我这个产品该按几类申报，走注册还是备案？
- 变更注册和变更备案怎么区分，哪些变更我自己维护就行？
- 体系核查前要准备什么，判定标准是什么？
