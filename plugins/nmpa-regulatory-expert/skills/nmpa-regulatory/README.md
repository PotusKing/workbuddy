# NMPA 医疗器械法规咨询 · Skill

> 十余年医疗器械法规从业经验的专家知识外化。覆盖有源 / 无源 / 体外诊断试剂（IVD）/ 独立软件四类产品，上市前（立项→申报→获证）与上市后（变更→监测→再评价）全流程。
>
> **定位：咨询解答平台，不是法规图书馆。** 输出的是「对您的情形意味着什么、怎么做、坑在哪」，不是条文复述。

## 安装

把整个 `nmpa-regulatory/` 目录放到：

```
~/.workbuddy/skills/nmpa-regulatory/
```

然后在 WorkBuddy 的「技能」页启用。技能由 `SKILL.md` 的 description 自动触发（问医疗器械法规、注册、分类、临床评价、体系核查、IVD、SaMD 等命中）。

## 结构

```
SKILL.md                     行为规则：定位、知识分层、回答工作流、术语纪律、维护机制
references/                  导航层（17 个域文件，全部为解读，非原文）
  qa-playbook.md             专家口径总表（已校准的实务判断）
  premarket.md / ivd.md      上市前注册：六章骨架、条文边界、时限
  qms.md / postmarket.md     体系核查、经营与上市后
  cmde-guidelines-index.md   CMDE 指导原则全量目录（1193 条，按域 + 按通告号）
  cmde-methodology.md        指导原则的方法学纪律（效力、结构、检索规则）
  official-qa.md             药监局答复口径索引（605 条器审中心共性问题 + 168 问百问百答）
  us-fda.md                  美国 FDA 参照层（法规三层、分类逻辑、路径判定、FY2027 收费、QMSR、中美对照）
  expert-views.md            专家个人主张（与现行法规严格区隔）
  regulation-index.md        法规时效状态清单（哪份现行、哪份被替代）
assets/templates/            申报资料模板（器械按 121 号、IVD 按 122 号的六章 Word 模板）
scripts/                     抓取与生成工具（CMDE 同步、索引重建、模板生成、PDF OCR）
```

**发布版不含绝大部分 `references/source-docs/`**（法规汇编、指导原则正文等约 12MB）。以下三类例外会随包发布，因为它们是「作答能力」而非「原文库」：

- `source-docs/cmde-qa/`（605 条共性问题 + 时效敏感清单）、`source-docs/official-qa/`
- `source-docs/qms/24-33`（2025 版 GMP 规范、2026 版检查指导原则总则+附录篇、IVD/义齿附录）
- `source-docs/us-fda/`（约 5.9MB，三层原文：法案 48 条 + 21 CFR 14 份 + CDRH guidance 600 份清单与 45 份全文）

### 美国 FDA 参照层的三层结构

不是为了把美国规矩搬过来，而是为了在讲中美差异时**能落到原文**，而不是凭印象：

| 层 | 位置 | 体量 | 答什么 |
|---|---|---|---|
| 法案 | `source-docs/us-fda/fdc-act/` | 48 条，1.2MB | 凭什么管、多久、多少钱。510(k)=§360(k)、分类=§360c、PMA=§360e、GMP=§360j(f)、收费=§379j |
| 法规 | `source-docs/us-fda/` | 14 份 21 CFR，约 640KB | 具体交什么、怎么写。820 QMSR / 803 MDR / 806 召回报告 / **7 召回分级** / 807 注册列名 / 812 IDE / 814 PMA / 830 UDI / 860 分类 / **801 标签 / 822 上市后监督 / 821 追溯 / 11 电子记录 / 4 组合产品** |
| 解释 | `source-docs/us-fda/guidance/` | 600 份清单 + 45 份全文，4.1MB | FDA 实际怎么把握尺度。清单按发布日倒序，可全文检索 |

法案与 guidance 都是英文原文，未翻译——判据不能带翻译损耗。中文只出现在导航层的摘要与「为什么收这份」提示里。

## 首次使用

原文库按需自建，见 `SKILL.md` 的「首次使用（bootstrap）」节。核心命令：

```bash
python scripts/cmde_crawl.py         # 抓 CMDE 指导原则目录与正式稿（约 20 分钟）
python scripts/build_cmde_index.py   # 重建索引
python scripts/cmde_sync.py          # 之后每 10 周增量同步
```

法规原文在 NMPA 官网「行政规范性文件」栏公开下载，按 `references/regulation-index.md` 清单补齐。

## 三层标注规则（使用时必须遵守）

本 skill 内所有内容都带层级标记，回答时不得混淆：

| 标记 | 含义 | 能否直接当结论 |
|---|---|---|
| 【专家口径】 | 已由从业者校准的实务判断 | 可以，并应说明它与法规文本的差异 |
| 【草稿】 | 通用框架、尚未校准 | 可以给，但须注明「未经专家校准，建议复核」 |
| 原文 / 条文号 | 可直接引用的法规文字 | 可以，须给文件全称与条款号 |

**指导原则的双重效力**是为本 skill 特别校准过的一条：文本上写「不作为法规强制执行」，但实操中就是强制标准。作答时不得因为看到「不强制」就暗示可以简化——需要替代方法时的正确路径是先沟通交流、再举证等效。

## 边界

- 不替代正式注册申报前的沟通交流，不构成法律意见。
- 法规有时效性。`regulation-index.md` 标注了入库时点与版本状态，涉及当下合规判断时以现行版本为准。
- 指导原则、标准原文版权归发布机构所有，本包不分发原文。
