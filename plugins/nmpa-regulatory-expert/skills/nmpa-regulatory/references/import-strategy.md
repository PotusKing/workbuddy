## 一、已确认的方向性定位

### 【专家口径】博鳌 / 大湾区政策属于进口产品上市策略，不是孤立的临时进口合规问题

**专家原话（2026-11-12）**：「所以你需要把博鳌和大湾区的政策也学习清楚。这对于你制定进口产品上市策略有直接影响。」

**结论**：评估这两条通道时，问题不是「能不能合法进口一批器械」，而是「这个产品以什么顺序、什么身份、用多长时间进入中国市场」。合规条款只是链条上的约束，**不是策略本身**。

**边界**：专家确认的是这一**定位**，不是下面第二节任何一条推导。第二节全部仍待逐条校准。跨域同步记录在 `qa-playbook.md` 同日条目。

## 二、接龙主链：七跳，每跳一个可证伪判断

链条：博鳌/大湾区政策 → 特许使用（不拿证）→ 真实世界数据 / 中国人群证据 → 临床评价路径被改写 → 进口注册证 → 境内生产（2025 年第 30 号）→ 集采 / 医保身份。旁支：市场预热。

### 跳 1【推导】特许使用不是「提前卖货」，是「把注册前的时间变成证据资产」

- 判断：企业评估这条通道时，不该按「能提前多久产生收入」算，该按「能提前多久攒到中国人群证据」算。
- 依据方向：97 号明确批复形式为综合司函、限于本机构特定医疗目的、不得常规销售；琼府〔2023〕16 号明确「自产品取得注册证后不再作为临床急需进口药械批准进口」——**特许窗口在拿证那一刻关闭**，它天然不是一个可持续的销售身份。
- 那又怎样 → 决定要不要走的判据，不是目标医院的市场容量，是**境外临床数据外推中国人群是否存在差异**。

### 跳 2【推导】真正的分叉点在临床评价路径，不在进口审批

- 判断：如果产品的作用机理、术式、操作者依赖、人群基线都不构成境内外差异，走特许使用攒数据的边际价值很低，应直接走常规进口注册；反过来，境外数据外推存疑的产品，特许使用是把「可能要在中国做临床试验」改写成「用真研数据补充」的现行通道（2020 年第 77 号第五（三）项正是以「外推可能受境内外差异影响」为触发条件）。
- 那又怎样 → **通道选择是临床评价策略的下游结论，不是独立的准入决策**。顺序做反了，会为不需要中国人群证据的产品白跑一两年真研。

### 跳 3【推导】政策把「要不要在中国做临床试验」从技术判断变成了时点决策

- 判断：77 号第五（二）项允许用境外真实世界证据补充、避免在原有证据不足时在中国境内开展临床试验；但「作为已有证据的补充」这个限定意味着特许使用数据一般不能独立撑起注册。企业实际面对的是「早启动真研 + 补证据」与「直接做中国临床试验」二选一，而前者能否被接受要到审评阶段才知道。
- 那又怎样 → **决策点比看起来更早**：在编制注册临床评价路径时就得定，不能等特许使用跑了一两年再回头想。这也是最容易发生沉没成本的一段。

### 跳 4【推导】乐城和大湾区不是同一个策略工具，选址由目标反推

| | 乐城 | 大湾区 |
|---|---|---|
| 制度性质【推导】 | **注册加速通道** | **区域可及性 + 市场验证通道** |
| 支撑 | 国家级真研试点、部省协同审评前置辅导、方案专题会/咨询会/申报前会三类沟通机制、「乐城研用 + 海口/琼海生产」产业政策、取证后关闭特许窗口形成闭环 | 71 家指定医疗机构名单制、目录内/外分流、支付端配套（惠民保、医保个账）、7 市纳入保障范围 |
| 准入硬条件 | 境外已批准上市 + 我国尚无同品种获准注册 | 临床急需 + **港澳公立医院已采购使用** + 临床应用先进性 |
| 缺什么 | — | **没有国家级真研试点制度、没有部省协同审评前置辅导、没有「研用 + 本地生产」专项产业政策** |

- 可证伪命题：以「尽快拿中国注册证」为唯一目标的产品优先乐城；以「验证中国市场、建立临床认知和支付路径」为目标的产品大湾区更匹配。
- 反例（这条判断的边界）：产品若未进入港澳公立医院采购，大湾区通道根本不成立，与策略偏好无关；产品若属国家真研试点不覆盖的品类，乐城的加速价值也要打折。
- 那又怎样 → **别拿政策优惠清单比大小**。准入条件是先决的，优惠是第二顺位。

### 跳 5【推导】全链最容易画错的一段是「特许使用 → 境内生产」

- 判断：2025 年第 30 号的硬前提是「**已获进口医疗器械注册证**」的二、三类产品。特许使用不产生注册证，所以「先在乐城用起来、再直接在海南本地生产」这条路**不存在**，中间必须插入一步正式进口注册。
- 那又怎样 → 海南「乐城研用 + 海口生产」讲的是**产业链布局**，不是同一份申请的连续动作。把它读成注册捷径，会把项目排期整体画错。
- 完整顺序：特许使用（可及性 + 证据）→ 正式进口注册（拿证）→ 境内生产（30 号公告）→ 支付身份。

### 跳 6【推导】拿到证不是终点，行政身份要换三次

- 判断：进口注册证、境内生产注册、医保/集采准入是三个独立身份，各有独立准入逻辑，**特许使用阶段的支付安排不自动延续到上市后**。乐城公开口径中「26 款获批上市」与「4 个进医保目录、1 个进商保创新药目录」的落差，本身就说明获批与支付是两道关。
- 那又怎样 → 真研数据的用途不止注册。海南 2025-11 措施已明确把真研从审评注册拓展到**上市后评价、医保准入**全生命周期；同一套数据若能一次设计、多处复用，边际收益远高于只服务于一次注册申报。这反过来影响跳 3 的研究方案设计（变量、随访、终点要不要兼顾支付方口径）。

### 跳 7【推导·旁支】市场预热被高估

- 判断：特许使用限于本机构特定医疗目的、逐家申请、不得常规销售，能建立的是 **KOL 临床认知、术式培训和共识基础**，不是渠道和销量。把它当试销，会系统性高估上市后的放量速度。

## 三、反向判据：什么产品不该走这条链

【推导】以下情形应直接放弃「特许使用 → 真研 → 注册」路径，改走常规进口注册或其他机制：

1. **国内已有同品种获准上市** —— 97 号、乐城两项准入同时不满足，大湾区还要另看港澳公立医院采购记录。
2. **境外临床证据充分、外推无境内外差异** —— 攒中国人群证据不产生增量，只增加时间与不确定性。
3. **按医疗器械管理的 IVD** —— 2024 年第 3 号真实世界研究指导原则明确不适用于 IVD 真实世界研究，整条链的方法学依据缺一块（原因见第四节空白 ④）。**在有专门规则前，不要把器械的真研链条直接套到 IVD 上**。
4. **应纳入大型医用设备配置许可管理的设备** —— 97 号第 1 条明文排除。
5. **生命周期短、迭代快的产品（如部分独立软件 / AI）** —— 特许使用攒数据的时间成本可能超过产品自身商业窗口；真研方案还没跑完，版本已经换了两代，数据与目标产品对不上。

| ① | **特许使用产生的真实世界数据权属归谁**？医疗机构、境外注册人还是申办方？企业投入做真研，数据能否完整调取用于注册申报？ | 97 号只规定病历保存 30 年、其他数据长期保存，规定的是**保管义务**，不是**权属与可携性**；三方质量协议约定的是质量安全责任，不是数据权利 |

| ⑤ | **同一产品在乐城与大湾区产生的数据能否合并用于一次注册**？以及特许使用数据用于「已上市产品适用范围变更」的边界在哪？ | 两地制度层级、准入条件、使用端管理均不同；7718/8718 号答复提到 RWE 可用于适用范围修改与上市后监测，但未给跨区域数据合并口径 |
