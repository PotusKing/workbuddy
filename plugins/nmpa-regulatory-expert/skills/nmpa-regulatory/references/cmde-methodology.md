## 一、指导原则的法律效力与事实效力（两者不一样）

**93%（687/736）** 的指导原则在开头都写了同一段话，措辞几乎逐字相同：

> 本指导原则是供注册申请人和技术审评人员使用的**指导性文件**，但不包括审评审批所涉及的行政事项，
> **亦不作为法规强制执行**，应在遵循相关法规的前提下使用本指导原则。如果有能够满足相关法规要求的其他方法，
> 也可以采用，但是需要提供详细的研究资料和验证资料。

**但这句话不能按字面理解成「可以参考」。实操中它就是强制标准**（专家口径，2026-10-22 校准）：

| 层面 | 事实 |
|---|---|
| 法律效力 | 指导性文件，不设定义务；理论可用等效方法替代 |
| 审评事实 | 审评就以指导原则为尺子；偏离即发补，企业实质没有「不遵守」的空间 |
| 例外成本 | 用替代方法要**自己举证等效**，举证成本 + 审评不确定性远高于照做 |

**为什么写「不强制」**：给技术争议留口子——新技术、新方法、进口已有成熟验证路径的产品。**不是**给企业留简化申报的空间。

**作答纪律（三层表述）**：
1. 对企业的实质建议：**按指导原则准备是唯一稳妥路径**。不要因为看到「不强制」就以为能省。
2. 确有更优方法时：先通过**沟通交流**取得认可，再写进申报资料；不沟通直接替代是发补高发点。
3. 只有在**没有对应指导原则**时（新技术、罕见品类），才按同类产品类推 + 通用原则，「不强制」的弹性才真正可用。

> 一句话：**别拿「不强制」当免死金牌**。用户可以这样问，但答案必须是「实际按强制对待」。
> 完整口径见 `qa-playbook.md`「指导原则的法律效力 vs 事实效力」。

## 二、标准骨架（736 份实测频次）

三段式几乎是通例：

| 段落 | 覆盖率 | 作用 |
|---|---|---|
| 一、适用范围 | **97%**（714/736） | 界定产品边界、分类编码、包含/不包含什么——**判断「我这产品适不适用」只看这段** |
| 二、注册审查要点（旧版称「技术审查要点」） | 59% + 9% = 68% | 主体，占全文八成以上篇幅 |
| 三、参考文献 | 85%（629/736） | 标准清单、国内外指南、方法学出处 |

「注册审查要点」内部按申报资料 ToC 分五段，**2022 年及以后发布的 470 份里，75%（357 份）五段齐全**：

| 子段 | 覆盖率（全样本） | 审评在看什么 |
|---|---|---|
| （一）监管信息 | 59% | 分类编码、注册单元划分、产品名称——**注册单元划分错误是最常见的退回原因之一** |
| （二）综述资料 | 77% | 产品描述、型号规格、工作原理、与同类产品的关系 |
| （三）非临床资料 | 55% | 产品技术要求（83% 的文件都单独展开）、检验报告、研究资料（性能/生物相容/灭菌/稳定性/软件…） |
| （四）临床评价资料 | 90% | 免临床 / 同品种 / 临床试验的路径选择与证据 |
| （五）产品说明书和标签 | 76% | 最终结论的载体，与前面所有研究结论必须自洽 |

**为什么不是 100%**：早期文件（2015 年前后）结构不统一；IVD 类走「主要原材料研究／分析性能／阳性判断值或参考区间／稳定性／临床评价」另一套骨架；独立软件类还有软件研究专章。**遇到 IVD 或软件产品，别硬套五段式**——那是器械主线的骨架。

**用法**：用户问「这个产品的申报资料怎么写」，不必读全篇，直接定位到他关心的那一段；五段里哪段缺、哪段弱，就是发补的高发区。

## 三、检索规则（省 token 的关键）

1. **先索引后全文**。在 `cmde-guidelines-index.md` 里按产品名/关键词/域找条目，确认有没有对应指导原则、有没有「修订版」。
2. **只看两段**。读全文只取「一、适用范围」+ 用户问到的那一段，不整篇加载。
3. **Grep 关键词**比读文件快：
   - 注册单元 / 型号规格 → 监管信息、综述资料
   - 性能指标 / 检验方法 → 非临床资料
   - 同品种 / 免于临床评价 / 临床试验 → 临床评价资料
   - 有效期 / 货架寿命 / 包装完整性 → 非临床资料
   - 网络安全 / 软件级别 / 算法 → 非临床资料（软件类另见 `software.md`）
4. **没有指导原则不等于没要求**。新产品常常没有专门指导原则，此时按上一层的通用指导原则 + 同类产品指导原则类推，并向用户说明这是类推而非直接适用。

## 四、三个容易踩的坑

1. **版本**：库里「修订版」占 **47%（347/736）**——近一半的指导原则已被修过。同名指导原则可能有三代（如 2015 原始版 → 2020 修订 → 2026 修订）。答之前务必确认用户产品申报时点适用哪一版，新版发布通常给过渡期。索引里带「修订版」字样的条目要特别注意，**别引用旧版去答新申报**。
2. **一个通告发几十项**：CMDE 常一次通告批量发布（如 2026 年第 24 号一次 57 项）。同通告的产品群往往共享一套方法学假设，检索时顺带看同通告其他条目。
3. **适用范围写得很硬**：指导原则开头的「本指导原则不适用于……」是排他性的，被排除的产品不能套用，要另找或按通用原则类推。
