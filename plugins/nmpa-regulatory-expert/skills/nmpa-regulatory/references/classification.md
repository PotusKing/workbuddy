# 分类判定与注册路径

> 问题域：产品属于哪类、按注册还是备案管理、监管属性判定。
> 使用前先读文件头部说明，区分【专家口径】与【草稿】。

## 一、专家口径

### 分类界定与直接申报 [2026-10-22]

- 新研制、未列入目录的产品，**实操仍应先做分类界定再申报**。
- 条例第十六条允许"直接按第三类申报"，但实操困难：**国产**尤其难——界定与注册的受理机构不同，路径打通成本高；**进口**相对可行，因界定与注册均在国家药监局层面。

## 二、【草稿】分类判定通用框架（未经校准）

### 判定依据

- 《医疗器械监督管理条例》（国务院令第739号）——风险分级管理：第一类低风险备案、第二类中度风险省级注册、第三类较高风险国家局注册
- 《医疗器械分类规则》（总局令第15号）——判定规则（接触部位、使用时限、有源/无源、侵入程度等）
- 《医疗器械分类目录》（2017年版）——目录化查询，含子目录序号结构
- 《关于调整〈医疗器械分类目录〉部分内容的公告》——历次动态调整

### 判定顺序（通用方法）

1. 先判**是否为医疗器械**（预期用途、使用方式，对照定义；疑似边界产品查属性界定文件）
2. 再查**分类目录**直接匹配（按使用形式 + 结构特征）
3. 目录不能直接对应时，用**分类规则**逐条判定
4. 仍不明确的，申请**分类界定**（向器械标管中心）

### 注册 vs 备案 vs 分类界定

- 第一类：备案（市级或相应部门），产品备案 + 生产备案
- 第二类：省级药监局注册
- 第三类：国家药监局注册
- 进口：无论几类均由国家药监局
- 软件产品：单独判定（详见 software.md 交叉引用）

### 注意

以上草稿的具体目录结构、最新调整动态需校准，特别是 2017 版目录历次调整后的现行状态。
