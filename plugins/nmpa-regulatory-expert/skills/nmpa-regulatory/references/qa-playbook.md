# 专家口径库（QA Playbook）

> 本文件是专家实务问答的滚动沉淀区。每次咨询后有价值的问题与专家判断，按格式追加。
> 追加原则：只记「通用法规知识推不出来的判断」，纯法条复述不记。

## 记录格式

```
### [YYYY-MM-DD] 问题一句话概括
**情形**：产品/背景关键事实
**结论**：一句话结论
**口径**：专家判断逻辑、审评/监管实际尺度
**边界**：结论不适用的情形
```

### [2026-10-22] 注册检验样品的生产方：可通过委托生产（MAH）解决
**情形**：注册检验样品必须由申请人自产吗？能否委托生产后送检。
**结论**：取决于产品的生产方式。**目前国内除《禁止委托生产医疗器械目录》内的品种外，其他产品都可以通过注册人制度（MAH）委托生产**，注册检验样品同理。
**口径**：注册检验样品不必自产——走委托生产即可，关键是委托生产合法合规（受托方具备相应生产许可/条件、签委托生产质量协议），样品生产工艺须与申报一致。
**边界**：禁止委托生产的品种除外（具体目录以现行发布为准）。

### [2026-10-22] 未列入目录产品：分类界定与"直接按三类申报"
**情形**：新研制的、尚未列入分类目录的产品，是否必须先做分类界定再申报注册。
**结论**：实操上仍应先做分类界定再申报。法规虽允许直接按第三类申报，但这条路径有很大实操困难。
**口径**：条例（第十六条）确实给了"可以直接按第三类医疗器械申请注册"的选择，但落到操作层面：**国产产品尤其困难**——分类界定与注册的受理机构不是同一个，路径打通成本高。**进口产品反而可操作性更强**，因为界定和注册都在国家药监局层面，窗口一致。
**边界**：结论的前提是"新研制、未列入目录"；已能对应目录的产品不涉及此问题。

### [2026-10-22] IVD 说明书变化：默认是变更注册，不是小改
**情形**：IVD 产品说明书内容需要调整，判断走哪条路径。
**结论**：IVD 说明书是**注册证书的组成部分**（注册证附件），因此一般来讲，说明书的变化都属于大的变更，**要走变更注册流程**。
**口径**：与器械不同——器械说明书有「说明书更改告知」通道，IVD **不适用**告知，只有信息性文字变化（联系方式、许可证号、注册证号、标识解释等，依据食药监办械管〔2016〕117 号）可自行修改；其余任何内容变化一律许可事项变更。
**边界**：信息性文字变化仍可自行修改，但错误援引 117 号文把实质内容变更当文字变更，是常见违规形态。

### [2026-10-22] 变更分类：官方无清单，按「重新审评结论会不会变」判断
**情形**：判断某项变更走许可事项变更，还是企业自行维护。
**结论**：官方没有「可自行维护变更」的完整清单，只有判断原则。实操锚点是：**假设该变更后的产品现在重新审评，审评结论（安全有效、准予注册）会不会变**——不会变 → 自行维护；会变 → 变更注册。
**口径**：判断分三层——①载明事项层（型号规格、结构组成、适用范围、软件版本，动了就是许可变更）；②技术要求层（性能指标/检验方法动了是许可变更；未动但实现路径变了看是否需重新验证）；③证据链层（原检验、临床评价、风险分析结论是否仍成立，成立则自行维护但须留「为什么成立」的验证记录）。
**配套习惯**：判为自行维护的，变更控制程序里须有「变更分类判断说明」，写明为什么不属于许可变更（核查时的依据）；拿不准的宁可申请变更注册——多办一次的成本远低于被认定「未批先变」。
**边界**：适用于器械；IVD 说明书另有规则——说明书是注册证组成部分，变化默认走变更注册，仅 117 号文列举的信息性文字变化可自行修改，且 IVD 不适用「说明书更改告知」（见同日另一条）；软件更新按重大/轻微判定（官方问答有源第 11 问）。

### [2026-10-22] 体系建立时点：注册检验样品生产前，运转至量产
**情形**：新企业建厂申报，质量管理体系应何时建立、覆盖哪段周期。
**结论**：「试产体系」不是规范说法。准确口径：**注册检验样品生产出来之前，对应产品的质量体系就必须建立完成**。此后经历注册检验 → 临床试验（如有）→ 产品注册 → 量产，整个周期体系须保持运转，但拿生产许可证前**不能量产**。
**口径**：中间这段「保持运转但不能量产」的空转期，确实造成人力、资源、投资的浪费——这是制度现实，没有办法，合规上没有回旋空间。
**边界**：适用于自产情形；委托生产情形下体系建立义务由注册人与受托方按 qms.md 07 号文件分担。

### [2026-10-22] 注册检验：自检与委托检验只能二选一
**情形**：新企业申报注册，检验报告来源的选择。
**结论**：一份递交申请的检验报告只能来自一个主体——要么全部自检，要么全部委托有资质机构，不可部分自检部分委托。
**口径**：实操中自检和委托检验是二选一的关系，不能混搭。（专家口径，2026-10-22 纠偏）
**边界**：同一注册申请内不可混；不同产品/不同申请各自独立选择。

### [2026-10-22] 指导原则的法律效力 vs 事实效力：写「不强制」，实操就是强制
**情形**：CMDE 指导原则开头普遍写明「不作为法规强制执行，可采用其他等效方法，但需提供研究资料和验证资料」。用户据此问：那是不是可以不按指导原则做？
**结论**：**文本上不强制，实操上就是强制**。审评就是拿指导原则当尺子量资料，偏离就要发补；企业实质没有「不遵守」的空间。答企业时不能只说「指导原则只是建议」，那会误导。
**口径**：
- 指导原则这句话是为**技术争议留口子**（新技术、新方法、进口已有成熟方法），不是给企业留「简化申报」的空间。要用等效方法，前提是**自己举证等效**，举证成本和审评不确定性远高于照做。
- 实操正确姿势：按指导原则准备 → 确有更优方法时，在申报前通过**沟通交流**取得认可，再写进资料；不要在没沟通的情况下直接替代，那是发补高发点。
- 对外表达分两层：法律效力上「指导性文件、不设定义务」；审评事实上「按它做是唯一稳妥路径，不按要付举证和沟通成本」。
**边界**：产品确无对应指导原则时（新技术、罕见品类），按同类产品类推 + 通用原则，此时「不强制」的弹性才真正可用；一旦有对应指导原则，实务中按强制对待。

### [2026-11-11] 产品技术要求指标怎么定：从分析性能研究数据取合理边界
**情形**：编制 IVD 产品技术要求时，性能指标与限值如何确定；与设计验证/分析性能研究的内容是否重合。
**结论**：两者不重合，交集只在**数据**不落在试验清单。指标从分析性能研究数据里取合理边界固化——定得太严，量产批批检不合格风险高、一动指标就触发许可事项变更；定得太宽，审评不认「不足以表征安全有效」。**（本条由草稿推导后经专家确认，即专家想表达的口径，2026-11-11 校准）**
**口径**：
- 正确链条：**研究数据定指标 → 技术要求固化为法定限值 → 按技术要求出注册检验报告**。研究是过程，技术要求是成品最小集，注册检验是对该最小集的判定。
- 技术要求只收「成品、可客观判定」指标（48 号令第 27 条）。2022 年第 8 号指导原则第四部分把「研究性及评价性内容」与「非成品相关内容」排除在外，而它对「研究性内容」的**原文定义恰恰是「设计开发阶段为确定产品某一特定属性而开展的验证性活动」**——所以这是制度刻意切分，不是巧合。
- 器审中心 2022-09-02 答复可作对照例：IVD「稳定性」可不纳入技术要求性能指标，但 122 号公告 3.6 的稳定性研究照交。**研究要做、PTR 不写**。
- 两个不能互相替代：研究资料写得全 ≠ 技术要求指标齐；注册检验报告 ≠ 设计验证报告（后者须有方案、接收准则、设计输入逐条对照与过程记录，《规范》第 54 条 / 检查项 7.8.2），但注册检验报告可援引为设计验证的证据之一。
- 指导原则文本写「不强制」的效力问题，按 [2026-10-22] 同库记录处理。
**边界**：本条在 IVD 场景下校准，器械通用部分属推导。具体品类该写哪几项、限值取几个标准差或百分位，仍依对应产品注册审查指导原则及有无适用国家标准品；定量（2022 年第 32 号）与定性（第 36 号）项目集不同；二类与三类在附录、三批检验报告上要求不同。**收紧限值能否反哺过程问题发现，见下一条（正解已校准）**。

### [2026-11-11] 内控标准与注册技术要求分离：对外合理、对内从严
**情形**：企业想靠收紧产品技术要求指标更早发现生产步骤的潜在问题，问这样做有没有用、指标该定在哪。
**结论**：收紧技术要求帮助有限——只提高成品端报警的**灵敏度**，不提供工序**分辨率**。正解是把两个标准分开：**注册技术要求保持法规认可的合理边界，企业内部另建更严的内控/放行标准与中间品控制点，配趋势分析（SPC）和批记录做过程监控。对外合理、对内从严，收益照拿，且不触发变更注册**。（本条由草稿推导后经专家确认，2026-11-11）
**口径**：
- 技术要求的核心性能指标是成品末端的**多工序合成结果**（原料、配制、包被、分装、冻干、校准等），一个超限结论不能反推是哪一步；收紧只是把报警线前移。
- 收紧到贴近检验方法自身变异时，超限反映的是方法波动而非工艺漂移，会把调查引向错误方向；误报多了还会造成 OOS 调查疲劳、真偏差被淹没。这是同一条逻辑的推论，不是并列的第二个原因。
- 定位到工序的机制长在过程控制侧：122 号 3.8 的主要原材料/生产工艺研究（本就按工序拆）、3.5 的多批评估；《规范》72 条与检查项 9.4.1（工艺参数是验证对象、技术要求只是判定基准）、9.4.2、9.6.1、9.7.1、10.5.1 物料平衡、11.3.2。
- **「不触发变更注册」的准确含义**：内控标准不是注册证载明事项。但内控/放行标准与检验方法的调整仍须走企业变更控制并按需验证确认（2.4.1、9.6.1，均为关键项）；若牵动技术要求、生产工艺、主要原材料或检验方法发生实质变化，仍要按变更注册/备案/生产事项变更报告办理。放行条件企业自定、可严于技术要求（11.10.1）；符合技术要求但不符合内控的产品不得直接放行，走偏差/OOS 程序。
**边界**：专家确认的是「内控与注册分离」这一正解本身，IVD 场景。**「分辨率/灵敏度/可追溯性」三件套、单工序可归因指标（装量↔分装、pH↔配制）适度收紧的例外、SPC 参数设定与内控限度取法，均未随本条校准，仍属草稿**（`ivd.md` 草稿段）。器械通用场景亦属推导。
