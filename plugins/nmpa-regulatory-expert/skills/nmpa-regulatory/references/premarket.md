# 上市前注册：首次注册 / 变更 / 延续

> 问题域：申报资料体系、审评逻辑、时限、各类型变更的路径区分。
> 使用前先读文件头部说明，区分【专家口径】与【草稿】。

## 一、专家口径

### 体系建立时点 [2026-10-22]

- **「试产体系」不是规范说法**。准确口径：注册检验样品生产出来之前，对应产品的质量体系就必须建立完成；此后注册检验 → 临床试验（如有）→ 产品注册 → 量产全周期体系保持运转，但获生产许可证前不得量产（专家口径）。
- 中间「空转期」的人力与投资浪费是制度现实，合规上无回旋空间——给企业做规划时应按此如实提示，不要给出「先试产后建体系」的错误时间线。
- 注：expert-views 长文第三章所用「试产或小批量验证状态」为描述性语言，非法规术语；引用时以本口径为准。

### 注册检验 [2026-10-22]

- **自检与委托检验二选一**：一份递交申请的检验报告只能来自一个主体，不可部分自检、部分委托（专家口径，已纠偏）。法规层面「可以是自检报告也可以是委托检验报告」的表述，实操中按互斥理解。
- **注册检验样品可通过委托生产（MAH）实现**：除《禁止委托生产医疗器械目录》内品种外，均可走注册人制度委托生产，样品不必自产（专家口径，2026-10-22）。

### 申报资料清单（47 号令第 52 条，七项）

提出注册申请须在完成安全性有效性研究、做好接受体系核查准备之后，通过在线途径提交：

1. 产品风险分析资料
2. 产品技术要求
3. 产品检验报告（自检报告或委托有资质检验机构出具，二者择一）
4. 临床评价资料
5. 产品说明书及标签样稿
6. 与产品研制、生产有关的质量管理体系文件
7. 证明产品安全、有效所需的其他资料

### ToC 六章 vs 47 号令七项资料（常被混淆，先分清再答）

47 号令第 52 条的「七项」是**法定资料类别**（法律层面的清单）；121 号公告的「六章」是**申报资料的编排结构**（形式层面的目录）。两者不是一一对应：

| 121 号 ToC 六章 | 对应 47 号令七项中的 | 说明 |
|---|---|---|
| 1. 监管信息 | （申请表等，不在七项内） | 行政性材料：申请表、营业执照、关联文件、符合性声明 |
| 2. 综述资料 | （不在七项内，但必备） | 产品是什么、跟谁比、上市历史 |
| 3. 非临床资料 | ① 风险分析 ② 技术要求 ③ 检验报告 | 七项里有三项落在这一章 |
| 4. 临床评价资料 | ④ 临床评价资料 | 一一对应 |
| 5. 说明书和标签样稿 | ⑤ 说明书及标签样稿 | 一一对应 |
| 6. 质量管理体系文件 | ⑥ 体系文件 ⑦ 其他资料 | 含 6.10 体系核查文件 |

**答用户时的正确表述**：「47 号令规定要交哪几类资料，121 号公告规定这些资料怎么编、怎么排、怎么签章」。只说七项会漏掉监管信息和综述资料两大章。

### 变更与延续的条文边界（47 号令第 79–85 条）

**走变更注册的（第 79 条）**：设计、原材料、生产工艺、适用范围、使用方法等发生**实质性变化**、可能影响安全有效的；以及注册证载明事项——产品名称、型号、规格、结构及组成、适用范围、产品技术要求、**进口医疗器械的生产地址**。

**走备案的（第 79 条）**：注册人名称和住所、代理人名称和住所等非实质变化，**变化之日起 30 日内**向原注册部门备案。

**境内生产地址变更**：先办生产许可变更，**再**办理备案（顺序不能反，实操常错）。

**变更审评逻辑（第 80 条）**：技术审评**只针对变化部分**，判断变化后产品是否仍安全有效质量可控；必要时可触发体系核查。变更文件与原注册证**合并使用，有效期同原证**（第 81 条）。

**延续注册（第 82–84 条）**：有效期届满**前 6 个月**申请；届满前未作决定的**视为准予延续**。不予延续仅三种情形：① 逾期未申请；② 新强制性标准已实施而产品达不到新要求；③ 附条件批准的产品未按期完成注册证载明事项。

### 时限基准（47 号令第七章，以**工作日**计）

| 环节 | 时限 |
|---|---|
| 受理后转技术审评机构 | 3 日 |
| 临床试验申请技术审评 | 60 日（补正后 40 日） |
| 二类注册/变更/延续 技术审评 | 60 日（补正后 60 日） |
| 三类注册/变更/延续 技术审评 | 90 日（补正后 60 日） |
| 三类体系核查启动 | 受理后 10 日内通知省局 |
| 省局完成核查并反馈 | 接到通知后 30 日内（原则上） |
| 审评结束后作出审批决定 | 收到审评意见起 20 日 |
| 颁发送达证件 | 决定之日起 10 日 |
| 注册证补办 | 收到申请起 20 日 |
| 延长时限上限 | 不超过原时限的 **1/2**，须书面告知申请人 |

**不计入时限的（第 98 条）**：申请人补充资料/核查后整改、因申请人原因延迟核查、专家咨询与药械组合联合审评、中止审评期间、**体系核查所占用的时间**。最后一项最容易被忽略——核查不占审评时限，但实际拉长整体周期。
