# 美国 FDA 医疗器械监管（参照层）

> **定位**：本文件不是第二个主域，是**参照层**。主作答口径仍是中国 NMPA。
> 启用条件：用户明确问美国/出海/FDA；或问「国外怎么做」「为什么中国要这样」。
> **不要主动把美国做法当建议推给用户**——两国法律基础不同，直接移植会出错。

**速查（600 行，按问题定位，别通读）**：

| 问题 | 去第几节 |
|---|---|
| 这东西算不算器械？（软件 / App / AI / CDS） | **五**（`§360j(o)` 五类排除） |
| 走哪条路上市？ | **四**（路径判定树 + De Novo 两程序 + IDE + 加速通道） |
| 改版了要不要重新报？PCCP 是什么？ | **六**（三档判定 + PMA 补充四型 + PCCP） |
| 只出口不内销，要不要管 FDA？CFG 怎么办？ | **七**（`§381`/`§382` 出口豁免） |
| 多少钱？ | **八**（FY2027 费率） |
| 体系、检查、召回、不良事件 | **九**（QMSR + 上市后义务 + 召回分级） |
| 中美到底差在哪？ | **十**（对照表） |
| **答之前该确认哪些机制？** | **十三**（触发词 → 机制自查，必过） |

## 一、使用纪律（先读这段）

1. **先判断用户要什么**：
   - 「美国这个产品怎么上市」→ 走第四节路径判定
   - 「中美有什么区别」→ 走第十节对照表
   - 「中国要求 XX，美国是不是也这样」→ 先答中国，再答美国，最后点出**为什么不同**（法律基础，不是水平高低）
2. **中美不互认**。FDA 清关不等于中国能注册，中国注册证也不被 FDA 承认。跨境项目要分开排期、分开预算。
3. **不要用中国概念套美国**。「注册证」「生产许可」「体系核查」「分类目录」在美国都没有一一对应物。用错词会把问题带偏。
4. **数字必须带年份**。FDA 收费每财年调整（10-01 起算），审评时限受 MDUFA 授权周期约束。写「FY2027」而不是「现在」。
5. **原文在 `source-docs/us-fda/`，分三层**：`fdc-act/`（48 条法案原文）→ 21 CFR 14 份（法规细则）→ `guidance/`（600 份清单 + 45 份核心全文）。答条文时先判断问题属于哪一层，再 Grep 关键词，不整篇加载。索引见第十二节。

## 二、法律架构：两层，不是一层

| 层级 | 文件 | 作用 | 中国对应 |
|---|---|---|---|
| **法律** | Federal Food, Drug, and Cosmetic Act（FD&C Act） | 国会立法。授权 FDA 管辖、定义「器械」、确立三类分类与上市前要求 | 《医疗器械监督管理条例》（国务院令第 739 号） |
| **法规** | 21 CFR Title 21（Chapter I, Subchapter H） | FDA 依授权制定的实施细则，具法律效力 | 部门规章 + 规范性文件 |

**关键差别**：美国是「**法律给框架、FDA 填细则**」，中国是「条例 → 办法 → 规范/指导原则」三层。但**不要因此低估法案的细度**——读到原文才知道，FD&C Act 并不只写原则：

- 有些条款确实只给原则：§360j(f) 只有一句「部长可制定 CGMP 法规」，全部操作细节在 21 CFR 820。
- 但另一些条款细到可以直接算数：**§379j(a)(2) 直接写了各类费用的比例**（510(k) = PMA 的 4.5%、De Novo = 30%、30 天通知 = 1.6%），**§360e(c)(3) 写了 PMA 审评的 180 天时钟怎么算**，**§360(k) 写了上市前 90 天报告**。
- 所以答案是：**程序性与时限性的规定多在法案里，技术要求多在 CFR 和 guidance 里**。

**读法**：问「凭什么管」「多久」「多少钱」→ 先查 FD&C Act；问「具体要交什么、怎么写」→ 查 21 CFR；问「FDA 实际怎么把握尺度」→ 查 guidance。

## 三、分类逻辑：按风险判定，不靠固定目录

FD&C Act 513(a)(1) 的三类定义，判断标准是「**现有控制措施够不够**」，不是产品叫什么：

| 类别 | 判定标准（513(a)(1)） | 上市前要求 | 中国大致对应 |
|---|---|---|---|
| **Class I** | 一般控制（general controls）足以合理保证安全有效 | 多数豁免 510(k)；仍需注册列名、MDR、QMSR | 一类（备案） |
| **Class II** | 一般控制不够，但有足够信息建立**特殊控制**（special controls：性能标准、上市后监测、指南、患者登记等） | 多数需 510(k) | 二类（注册） |
| **Class III** | 一般+特殊控制都不足以保证安全有效；且用于支持/维持生命、或对防止健康损害有实质重要性、或存在不合理伤害风险 | PMA | 三类（注册） |

**最容易搞错的一点**：美国**没有一部「分类目录」**。判定入口是 FDA 的 Product Classification 数据库（按产品代码 product code 查），而 1976-05-28 之后上市、又没被分类的新器械，**法律上自动归 Class III**（21 U.S.C. 360c(f)(1)），除非 FDA 通过 De Novo 或 513(f)(2) 把它降到 I/II 类。

> 这条「自动归 III 类」是美国制度的核心阀门：创新产品不是"没路径"，而是"默认最高路径，需要主动申请降级"。中国的对应阀门是「分类界定申请」——同样要申请，但中国是**先定类别再走路径**，美国是**先用最高路径再看能不能降**。

## 四、上市前路径判定（按顺序问）

```
1. 是「通用健康产品」（general wellness）吗？
   → 是：不属于器械，不适用器械要求（2026-01-06 更新指南）
   
2. 有 510(k) 豁免吗？（21 CFR 8xx.9 / 510(m) 豁免清单）
   → 有：不用交 510(k)，但仍需注册列名 + QMSR + MDR

3. 有合法 predicate（对比器械）且能证明实质等同吗？
   → 能：510(k)（传统 / 简略 Abbreviated / 特殊 Special）
   
4. 没有 predicate，但风险可通过一般/特殊控制管理？
   → De Novo 分类请求（513(f)(2)）——批准后即为 I 或 II 类，并产生新 predicate

5. 以上都不行，或风险高到必须 PMA
   → PMA（515）；罕见病器械可走 HDE（520(m)）
```

**辅助工具**：

- **513(g)**：只想知道「我这东西算几类、走什么路径」，可向 FDA 申请分类信息答复（收费，FY2027 标准 $8,596）。注意它只给答复，**不产生 predicate**，也不能替代 510(k)/De Novo。
- **Pre-Sub（Q-Sub）**：正式提交前的沟通会，免费。De Novo 和 PMA 前强烈建议做。Pre-Sub 的意见**不构成批准**，但 FDA 事后推翻自己意见的成本很高，实务上相当于一次预审。

### 4.1 De Novo 有两条程序，别混

这是最常被讲错的一处。`§360c(f)` 下有两条独立通道：

| | **(f)(2) 分类请求**（狭义的 De Novo） | **(f)(3) 重新分类请愿**（petition） |
|---|---|---|
| 适用 | 无合法 predicate 的新器械，自动归 III 类后主动请求分类 | 已被归为 III 类、想降级 |
| 主体 | 申请人 | 申请人**或部长主动** |
| 前置 | 见下两种入口 | 无 |
| 时限 | 收到请求后 **120 天**内分类 | 有 panel 参考时 panel 90 天内建议；部长收到建议后 90 天内、且不晚于申请后 **210 天**作出命令 |
| 结果 | 分类令，**并成为 predicate** | 分类令 |
| 频率 | 主流路径 | 历史路径，现在很少用 |

**(f)(2) 的两个入口**（易错点）：

- **(A)(i)**：先交 510(k)，收到「归为 III 类」的**书面通知**后，再请求分类。
- **(A)(ii)**：申请人自行判断**没有合法上市器械可作实质等同基础**，**可以直接提交分类请求，不必先交 510(k)**。

**但 (A)(iv) 给了 FDA 拒绝受理 (ii) 的口子**：若 FDA 找到了可作 SE 基础的合法上市器械，或认定该器械不是低-中风险、一般控制不足且特殊控制无法制定，可以直接 decline。所以「直接提 De Novo」不是必然被接受，Pre-Sub 先探口风很值。

**两个后果要记住**：

- 分类令下达后，该器械**成为 predicate**（(f)(2)(B)(i)）——这是 De Novo 真正的价值：不只是让自己上市，更是给后来者开了一条路。
- 仍留在 III 类的器械，在获 PMA 批准或 IDE 豁免前**视为掺假**（(f)(2)(B)(ii)）。不是「不能卖」，是「法律上就是假劣产品」。

### 4.2 附件（accessory）按自身风险独立分类

`§360c(f)(6)`（2017 年 Cures Act 加入）：**附件按它自己的风险和使用场景定类，不跟随它所配合的主器械**。

这条与中国差别很大。中国实务中「配合主器械使用的附件」通常随主器械一起管理（同一注册单元或按主器械类别判定），美国是**可以分开定类、分开走路径**的：一个 III 类主器械的附件完全可能是 II 类甚至 I 类。

实操含义：如果一个附件被主器械的 PMA「带进去」了，厂家仍可依 (f)(6)(C)/(D) 请求把它**单独分类**，从而降低后续变更的负担。这是中美之间一个常被忽略的成本优化点。

### 4.3 其他四条加速/简化通道

| 通道 | 依据 | 实质给什么 | 不给什么 |
|---|---|---|---|
| **Breakthrough Device** | §360e-3 | 优先审评、与资深审评员频繁互动、可分段递交、**突破性器械的补充申请也优先** | 不降证据标准、不缩短法定时钟、不免费 |
| **Safety and Performance Based Pathway** | guidance 1.07 | 用「FDA 已确立的性能基准」替代 predicate 直接比对，**可省掉与 predicate 的逐项对比** | 仅适用于 FDA 已发布性能基准的器械类型；仍要交 510(k) |
| **510(k) 第三方审评** | §360m | 由 FDA 认可的第三方（Accredited Person）审，通常快于 FDA 自审 | 仅限 FDA 列入清单的器械类型；FDA 保留最终决定权，可退回自审 |
| **HDE** | §360j(m) | 罕见病器械免「有效性」证据，只需安全性 + 可能获益 | 限 **8000 人/年**；不得用于商业分销获利（有例外） |

> Breakthrough 的准入门槛原文是「为危及生命或不可逆衰弱性疾病提供更有效的治疗或诊断」——注意是**更有效**（more effective），不是「更好用」或「更便宜」。达不到这个比较级，只能走常规通道。

### 4.4 IDE：30 天默认批准，且自带变更控制

- **§360j(g)(4)(A)**：IDE 申请提交后**第 30 天视为批准**，除非 FDA 在此前下令不批准。这与中国的临床试验审批（明确批准制）是两种治理逻辑：美国是「沉默即通过」，责任前移到申办者。
- **(g)(6)**：IDE 生效期间，**不构成设计或基本原理重大变化**的开发性变更（含工艺变更）、以及不影响数据有效性的方案变更，**无需另行批准**。这是 IDE 层面的变更控制，逻辑上就是 PCCP 的前身。
- **SR / NSR 分级不在法案里，在 21 CFR 812.3(m)**：significant risk 指植入体内的、支持/维持生命的、或对诊断治疗有实质重要性的器械，且存在严重风险。**NSR 器械不需要 IDE**，只需 IRB 批准 + 知情同意 + 简化记录（812.2(b)）。所以「要不要交 IDE」的第一问不是器械类别，是 **SR 还是 NSR**。


### 三种 510(k) 的区别

| 类型 | 适用 | 特点 |
|---|---|---|
| Traditional | 常规 | 完整对比 predicate |
| Special | 只改制造方法/材料等，**无**性能与适应证变化 | 审评 30 天，最省 |
| Abbreviated | 有 FDA 认可的共识标准或 guidance，可引用 | 靠"引用标准"减少数据 |

### 法定审查时钟（FDA days，不含申请人应答时间）

| 路径 | 时限 | 说明 |
|---|---|---|
| 510(k) | 90 天 | 收到日起算；发 AI（Additional Information）要求时**时钟暂停**，实际常 4–8 个月 |
| De Novo | 120 天 | 受理后 15 日内告知是否受理 |
| PMA | 180 天 | 含顾问委员会环节；实际 1–2 年 |
| IDE | 30 天 | 30 天内未否决即可开始 |

> **务必提醒用户**：「90 天」是 FDA 的审查时钟，不是从提交到拿证的时间。企业补资料的时间不计入，这是中美落差最大的一个认知点——中国注册的"排队时间"在美国体现为"补资料时间"，形态不同但都会发生。

## 五、软件与 AI 的定性边界（`§360j(o)`）

这是软件类产品**第一个要回答的问题**，答错方向后面全错。而且中美在这一点的**法律层级不同**：美国写在法案里（法定排除），中国写在指导原则里（判定标准）。

### 5.1 五类法定排除（`§360j(o)(1)`）

以下软件功能**不属于「器械」**，因而不受任何器械要求约束：

| 项 | 排除内容 | 关键限定 |
|---|---|---|
| **A** | 医疗机构行政支持：财务、报销、排班、业务分析、患者人群信息、入院、库存、历史理赔数据分析、健康福利资格判定、群体健康管理、检验流程 | 纯行政，不涉诊疗判断 |
| **B** | 维持或促进健康生活方式 | 必须**与疾病的诊断、治愈、缓解、预防、治疗无关** |
| **C** | 电子病历（含患者提供的信息），仅用于传输、存储、转换格式、显示纸质病历的等价物 | 三个条件同时满足：①由专业人员或在其监督下创建/存储/审查；②属 42 U.S.C. 300jj-11(c)(5) 认证的卫生信息技术；③**不解释或分析**病历（含医学影像）用于诊疗 |
| **D** | 传输、存储、转换格式、显示检验数据或器械数据及其结果、专业人员对结果的判断、相关背景信息 | **不解释或分析**检验/器械数据、结果与判断 |
| **E** | 显示、分析、打印患者医学信息（含同行评议文献、临床指南）；向专业人员提供预防/诊断/治疗的建议 | 三个条件同时满足，见下 |

**(E) 的三条件是 CDS 判定的核心**，缺一即落入器械：

1. 功能限于显示、分析、打印医学信息或提供建议；
2. 面向**医务人员**（不是患者自主使用）；
3. 使医务人员**能独立审查该建议的依据**，且产品意图**不是**让医务人员主要依赖该建议作出临床诊断或治疗决定。

> 第 3 条是可解释性要求的法律来源。「黑箱只给结论、不给依据」的 CDS，即使面向医生，也**不满足** (E)，属器械。这一点在 2026-01-29 定稿的 CDS guidance 里有更细的判读。

### 5.2 三条配套规则

- **(o)(2) 多功能产品**：一个产品里既有非器械功能、又有器械功能时，**非器械功能不按器械管**；但 FDA 在评估器械功能的安全有效性时，**可以评估非器械功能对器械功能的影响**。所以「搭车功能」不能拿来规避，也不能假装无关。
- **(o)(3) 回捞机制**：对 C/D/E 三类的排除**不是绝对的**。若部长认定该功能「合理可能造成严重不良健康后果」，可经**联邦公报公告 + 不少于 30 天公众评议 + 最终命令**，把它重新纳入器械定义。这是国会给 FDA 留的后门，实务上极少启动，但答「会不会哪天被管起来」时这是准确答案。
- **(o)(4)**：本条不限制 FDA 的执法裁量权，也不影响血液制品相关软件、以及符合 III 类标准的软件的监管。

### 5.3 中美对照

| | 美国 | 中国 |
|---|---|---|
| 层级 | **FD&C Act 法定排除**（`§360j(o)`） | 《医疗器械软件注册审查指导原则》+ 分类界定 |
| 判定方式 | 五类清单 + (E) 三条件 | 按「是否用于疾病诊断治疗」+ 分类界定申请 |
| 健康生活方式 | 明文排除 | 有「健康管理软件」相关判定，边界更模糊 |
| 电子病历 | 明文排除（三条件） | 一般不作为器械，但无同等级别的法定条文 |
| CDS | 三条件必须同时满足，**可解释性是硬门槛** | 《人工智能医疗器械注册审查指导原则》按「辅助决策 / 非辅助决策」二分 |

> 讲差异时要说清：美国的排除是**国会立法**，改动要走修法；中国的判定是**指导原则**，修订只需中心发文。所以中国的边界调整更快，但也更依赖具体审评口径。

## 六、变更管理：先分三档，再选路径

美国的变更管理不是「一套规则」，是**三个层次**，混着答一定错：

```
第 1 问：这个变更，按判据要不要重新报批？
  ├─ 不要 → 走 QMSR 变更控制（记 DMR；PMA 器械在定期报告里报）
  └─ 要   → 第 2 问：走哪条报批路径？
              ├─ 510(k) 器械 → 新 510(k)
              ├─ PMA 器械   → PMA 补充（分 4 种，见下）
              └─ 已获批 PCCP → 落在 PCCP 范围内 → 不报批，按 Protocol 执行
```

### 6.1 第 1 问：要不要报批（判据在哪）

| 器械 | 判据文件 | 核心标准 |
|---|---|---|
| 510(k) 器械的一般变更 | guidance `1.02`（2017-10-25） | 是否「可能显著影响安全有效」——按标签、技术、材料、工艺四类走判断流程图 |
| 510(k) 器械的**软件**变更 | guidance `1.03`（2017-10-25） | 同上但更细，专为软件设计 |
| PMA 器械的变更 | guidance `2.01`（2008-12-11） | 「PMA 补充判定流程」 |

### 6.2 第 2 问：PMA 补充有四种，别只会说「补充申请」

| 类型 | 适用 | 审评时限 |
|---|---|---|
| **30 天通知** | 对已批准器械的微小制造/标签变更，不影响安全有效性 | 30 天 |
| **Real-time 补充** | 小范围设计变更、软件变更 | 实时（随到随审） |
| **180 天补充** | 中等变更 | 180 天 |
| **Panel-track 补充** | 影响较大的变更，需顾问委员会介入 | 含 panel 环节 |
| **PMA 新申请** | 变更大到改变预期用途或风险收益比 | 全套 PMA |

费用比例见第五节：panel-track = PMA 的 80%、180 天补充 = 15%、real-time = 7%、30 天通知 = 1.6%。

### 6.3 PCCP：把「变更审批」前置成一次范围授权

**法律依据**：`§360e-4`（FD&C Act §515C），2022-12-29 由 FDASLA §3308(a) 加入。

**机制**：上市前把「未来打算怎么改、怎么验证、达到什么标准算合格」一次写清报批。批下来后，落在范围内的改动按约定方法验证即可实施，**不再逐次报批**。

**三个组成部分**（2025-08-18 定稿 guidance 定义）：

| 组成 | 内容 |
|---|---|
| **Description of Modifications** | 改什么，改到什么规格和性能 |
| **Modification Protocol** | 怎么验证：数据管理实践、再训练实践、性能评估、更新程序四块，含**预设的接受标准** |
| **Impact Assessment** | 改动引入的获益与风险，以及 Protocol 的验证如何覆盖住 |

**两条硬限制**（原文明确，最容易漏）：

1. **只覆盖「本来就要报批」的变更**（`§360e-4` 引言 + 21 CFR 807.81(a)(3) / 814.39(a)）。不需要报批的变更不进 PCCP，走 QMSR。所以 PCCP **不是变更管理的替代品**，它是「许可事项变更的提前一次性审批」。
2. **predicate 锁定**：`§360e-4(c)` 明确，按 PCCP 改过的版本**不能**作为别人的 predicate，只能用变更前那个版本。防止 predicate 靠 PCCP 无限漂移。

**适用路径**：PMA（(a) 免除补充申请）、510(k)（(b) 免除新 510(k)，前提是仍与 predicate 实质等同）、De Novo（guidance 把 marketing submission 定义为含 De Novo request）。

**中国目前没有对等制度**，但有两条「半程」机制在功能上部分替代（2026-11-12 重学修订：此处原文误指 `qa-playbook.md` 的 PCCP 条目，**该条目并不存在**，已改为在本处列明；两条均属【推导·未校准】，不是专家口径）：
- 轻微软件更新（体系内控制，事后判定）
- AI 数据驱动型更新（看性能评估是否与前次**注册**有统计学显著差异）

核心差别是 **事前批准范围 vs 事后企业判定**。最根本的分水岭是算法能否在临床端持续学习：中国现行要求「关闭自学习功能，或开放但不得投入使用」，美国 PCCP 正是为持续迭代设计。

## 七、出口：不卖到美国，也可能受 FDA 管

这是中国企业最容易误解的一节。常见错答：「我们只出口，不在美国卖，所以不用管 FDA。」**不一定对**，取决于出口从哪里发、发到哪里、产品有没有美国身份。

### 7.1 `§381(e)(1)`：出口豁免的四个条件

拟出口的器械**不因不符合本法而被视为掺假或错标**，只要同时满足：

- (A) 符合**外国购买者**的规格；
- (B) 不违反**出口目的国**法律；
- (C) 运输外包装标注**仅供出口**；
- (D) **不在美国国内商业中**销售或要约销售。

四条缺一不可。注意 (A)——是「买方规格」不是「美国要求」，这是豁免的法理基础：美国不把自己的标准强加给别国市场。

### 7.2 `§381(e)(2)`：三类器械拿不到这个豁免

上述豁免**不适用于**：

- (A) 不符合 `§360d`（性能标准）或 `§360e`（PMA）要求的；
- (B) 依 `§360j(g)` 豁免于上述条款的（**IDE 器械**）；
- (C) 依 `§360f` **被禁用**的器械。

这三类要出口，必须额外满足其一：
- (i) 部长认定出口**不违背公共卫生与安全**，且**获目的国批准**；或
- (ii) 该器械依 `§382` 符合出口条件。

### 7.3 `§382`：白名单国家出口

`§382(a)` 把上述三类器械定性为掺假、错标、违法，除非出口依 (b)/(c)/(d)/(e) 获授权。

**`§382(b)` 的核心是「白名单」**：不符合美国要求的器械，可以出口到**任何国家**，只要①符合该国法律，②取得该国**有效上市许可**，且该许可来自下列之一：

> 澳大利亚、加拿大、以色列、日本、新西兰、瑞士、南非，或欧盟/欧洲经济区国家（在该国已上市，或已获 EEA 一般上市许可）。

部长可增列国家，条件是对方有药械安全有效性审查制度 + GMP 要求 + 对等安排。

**实务含义**：一个只拿了 CE 或日本 PMDA 批准、没走 FDA 路径的器械，理论上可以经美国转口到这些市场——但**不能在美国境内销售**。反过来，这也解释了为什么美国对「转口」的合规审查很严。

### 7.4 CFG（Certificate to Foreign Government）—— 投标最常要的那张纸

`§381(e)(4)`：

- 任何人出口器械，可请求 FDA 出具书面证明：证明符合 (e)(1) 条件，或符合本法适用要求。
- FDA 须在收到请求后 **20 天**内出具。
- 收费**不超过 $175**/份。

**门槛（`§381(e)(4)(F)`）**：境外企业要拿 CFG，前提是——该企业在 `§360` 下**已注册**、器械已按 `§360(j)` **列名**、且该器械**已获 clearance/approval 或依 `§360(l)/(m)` 无需上市前报告**，并且该器械**进口或要约进口到美国**。

也就是说：**CFG 不是「出口证明」，本质是「这个产品在美国是合法的」的证明。** 没在 FDA 注册列名的产品拿不到 CFG。很多中东、东南亚、拉美的招标要求 CFG，企业往往到投标时才发现要先补 FDA 注册列名——这个周期要提前排。

**被拒可申诉**（`§381(e)(4)(E)`）：FDA 拒绝出具须书面说明依据；若拒绝理由是企业不符合 21 CFR 820，须给出不符合项的具体摘要；已提交整改计划（response to Form 483）的，不得仅以 483 为由拒绝。

### 7.5 出口的四个常见错答

| 错答 | 事实 |
|---|---|
| 「不卖美国就不用管 FDA」 | 从美国境内出口、或产品有美国身份（注册列名/clearance）时仍受管；转口受 `§381`/`§382` 约束 |
| 「出口豁免 = 什么都不用做」 | 四个条件缺一不可，且三类器械（不合规/IDE/被禁）拿不到豁免 |
| 「CFG 就是出口许可证」 | CFG 是「产品在美国合法」的证明，前提是已注册列名 + 已 clearance/approved/exempt |
| 「拿了 CE 就能出口任何地方」 | `§382(b)` 白名单只是「经美国转口」的条件之一，还要符合目的国法律并取得该国许可 |

## 九、体系与上市后义务

### 9.1 QMSR（2026-02-02 已生效，最重大的变化）

21 CFR 820 原「质量体系规范（QSR）」已被「**质量管理体系规范（QMSR）**」取代：

- **机制**：以「援引并入」把 **ISO 13485:2016** 全文纳入 Part 820（§ 820.7），另援引 ISO 9000:2015 第 3 章术语
- **冲突规则**：ISO 与 FD&C Act 或其它 FDA 法规冲突时，**法案优先**（§ 820.1(b)）
- **删掉的部分**：原 QSR 的 820.20–820.30（管理职责、设计控制、文件控制、采购控制等）**全部标为 [Reserved]**，内容交给 ISO 13485；820.5、820.40 同样 Reserved

**QMSR 实际只剩 6 条，但信息量集中在这几条里**：

| 条款 | 内容 | 为什么重要 |
|---|---|---|
| § 820.1 | 适用范围 | 覆盖成品器械制造商，含合同灭菌、安装、重贴标、再制造、重新包装、 specifications developer，以及境外企业的初始分销商 |
| § 820.3 | 定义 | 保留 FDA 侧定义（如 finished device） |
| § 820.7 | 援引并入 | 法律上把 ISO 13485 变成美国法规 |
| **§ 820.10** | **QMS 要求（核心桥接条款）** | 见下 |
| § 820.35 | 记录控制 | 在 ISO 13485 §4.2.5 之上加：投诉记录（含器械名、UDI/UPC、投诉性质、纠正措施、答复）、服务记录 |
| § 820.45 | 标签与包装控制 | 标签完整性、包装作业控制 |

**§ 820.10 是理解 QMSR 的钥匙**，它把 ISO 条款和 FDA 其它法规挂上钩：

- (a) 按 ISO 13485 建立并**形成文件**的 QMS
- (b) 条款对映：ISO 7.5.8（标识）→ 21 CFR 830 UDI；ISO 7.5.9.1（可追溯）→ 21 CFR 821；ISO 8.2.3（向监管机构报告）→ 21 CFR 803 MDR；ISO 7.2.3/8.2.3/8.3.3（忠告性通知）→ 21 CFR 806 召回
- **(c) 设计开发：只对 Class II、Class III，以及「由计算机软件自动化的 Class I 器械」和表列 Class I 器械强制适用 ISO 13485 §7.3**。普通 Class I 器械不要求设计开发控制——**这条与中国 GMP 不同，中国除豁免外普遍要求设计开发**
- (d) 支持/维持生命的器械：额外适用 ISO 7.5.9.2（植入器械可追溯）
- **(e) 执法钩子：不符合本 Part 的任何要求，器械即构成 FD&C Act 501(h) 项下的「掺假」（adulterated）**

- **检查方式变了**：QSIT 停用，改用合规程序 **7382.850**；旧程序 7382.845 与 7383.001 同时作废
- **术语变了**：QMSR **不再使用** DHF、DMR、Design Controls、Design Validation、Process Validation 这些词；对应要素在 ISO 13485 第 4.2 条与第 7 章，用 ISO 的语言表述。答美国体系问题时应改用 ISO 术语，否则会对不上检查员的问法

**对中国企业的直接影响**：如果企业已按 GB/T 42061-2022（等同采用 ISO 13485:2016）建体系，**体系文件本体基本可直接对接美国要求**，差距主要在 820.35 的 FDA 附加记录字段、820.45 标签包装控制，以及美国代理人、注册列名等行政义务。这是中美之间**最接近**的一块，也是中国体系证书含金量上升的原因。

### 9.2 上市后义务一览

| 义务 | 依据 | 要点 | 中国对应 |
|---|---|---|---|
| 企业注册 + 产品列名 | 21 CFR 807 | 每年 10-01~12-31 更新；外国企业须指定**美国代理人** | 生产许可/备案 + 注册证（无"列名"概念） |
| 医疗器械报告 MDR | 21 CFR 803 | **按主体分三档**：制造商 30 日历日（死亡/严重伤害/故障），需采取补救措施防重大公共卫生风险或 FDA 书面要求时 **5 工作日**；进口商 30 日历日；**使用机构（user facility）10 工作日**（死亡报 FDA+制造商，严重伤害报制造商）。另有年度报告 | 不良事件监测（总局令第 1 号） |
| 纠正与移除（召回） | 21 CFR 806（报告）+ **21 CFR 7（分级与程序）** | 实施后 **10 工作日**内报 FDA。**分级见 9.3**——先分清是 recall 还是 market withdrawal，这一步错了整条处置链都错 | 召回管理办法（总局令第 29 号），分一/二/三级 |
| UDI 唯一标识 | 21 CFR 830 | 标签标 UDI + 向 GUDID 提交数据；已按风险分批全面实施 | UDI 系统（NMPA 数据库） |
| 上市后监督 | FD&C Act 522 + **21 CFR 822** | FDA 可对特定器械下令做上市后监测，要交监督计划、按频次报告，达标后终止 | 定期风险评价报告（PMSR） |
| 器械追溯 | **21 CFR 821** | 对植入类等器械要求追踪到患者/经销商 | 部分品类有追溯要求 |
| 禁止行为（prohibited acts） | FD&C Act 331 / 501 / 502 | adulterated（掺假）/ misbranded（错标）；这是 FDA 执法的两大抓手 | 条例中的违法情形 |

### 9.3 召回：先分清三个概念（`21 CFR 7.3`）

这三个词经常被混用，但在美国法下后果完全不同：

| 概念 | 定义（7.3 原文要点） | 要不要报 806 | 后果 |
|---|---|---|---|
| **Recall** | 对**已上市**违法产品的移除或纠正，且 FDA 会据以采取法律行动（如扣押） | **要** | 进 FDA 召回数据库、公开公示、做效度检查 |
| **Market withdrawal** | 移除或纠正**轻微违法**（FDA 不会起诉）或**根本不违法**的情形，如正常库存轮换、设备例行调整 | 不要 | 不构成召回，无需公告 |
| **Stock recovery** | 产品**尚未上市**或**未离开企业直接控制** | 不要 | 属上市前处置 |

**分级（7.3(m)）**，按健康危害程度：

- **Class I**：使用或接触该产品有**合理可能造成严重不良健康后果或死亡**
- **Class II**：有合理可能造成**暂时或可逆**的健康不良后果，或严重不良后果的可能性很小
- **Class III**：有合理可能造成**不太可能发生**的健康不良后果

> 中国《医疗器械召回管理办法》也分三级，一级/二级/三级的危害描述与 FDA 的 Class I/II/III **方向一致但不完全等同**。做中美双报时不要直接套用分级结论——同一事件在两边可能落到不同级别，因为判定锚点（是否「严重」）的尺度不同。另注意：**中国的「召回」定义比美国宽**，美国把 market withdrawal 排除在 recall 之外，中国没有这个二分。

## 十、中美对照表（核心）

> 讲对照时**先讲机制差异，再讲代价**。两国都在解决同一个问题：如何在不拖死创新的前提下保证安全有效。选择了不同的着力点。
>
> **2026-11-12 重学补注**：下表按维度并列，**会让人误以为这是 8 个互相独立的差异**。按接龙重走后可以确认，其中「审批性质 / 变更管理 / 体系监管 / 生产许可 / 证据复用 / 分类依据」六项，其实是同一个根节点（**谁举证、监管在哪个时点结算、结算结果以什么形式存在**）长出来的末端。讲机制时先走 `references/mechanism-chains.md` 的六条链，再回来看这张表当速查；只念表格答「为什么中国是这样」会答不到根上。

### 10.1 制度设计

| 维度 | 美国 FDA | 中国 NMPA |
|---|---|---|
| **分类依据** | 按「控制措施是否充分」逐品种判定，无固定目录；新产品**自动归 III 类**，需主动降级 | 按《分类规则》+ 分类目录；无对应条目时申请**分类界定** |
| **上市前审查的锚** | **实质等同（SE）**——与已上市的 predicate 比 | **技术审评**——按申报资料要求逐项审 |
| **证据复用** | 强。predicate 一旦存在，后续同类产品可低成本复用其结论 | 弱。每个产品独立提交完整资料，虽有同品种临床评价路径，但资料仍需自成体系 |
| **审批性质** | 多数为「备案式许可」：510(k) 是**企业声明 + FDA 不反对** | 行政许可：注册证是**行政机关的授予** |
| **体系监管** | QMSR = ISO 13485 + FDA 附加条款；检查随风险触发，**独立于上市前申请程序** | GMP（2025 版规范 + 附录）+ 分类分级检查；**注册体系核查是发证前必经关卡**（编入注册程序、占注册时限、不通过不予注册）。47 号令第 47 条「认为有必要」的主语是药监部门，是监管方判断权、不是企业可主张的「可能不查」——**按必查准备**（2026-11-12 晚间恢复，见 `SKILL.md` 中文阅读纪律） |
| **生产许可** | **无**。企业注册（registration）是登记性质，不是许可 | **有**。生产许可/备案是独立行政许可 |
| **变更管理** | 企业自行判断是否需要新提交（新增适应证、重大设计变更等需新 510(k)/PMA supplement）；FDA 事后追责 | 变更分登记事项/许可事项，**按清单报批**；IVD 说明书变化走变更注册 |
| **法律责任** | 民事赔偿 + 刑事 + FDA 行政强制（警告信、禁令、seizure）；**产品责任诉讼**是主要威慑 | 行政处罚为主（罚款、停产、吊证）；民事赔偿体系尚在发育 |

### 10.2 时效与成本（体感差异的来源）

| 维度 | 美国 | 中国 |
|---|---|---|
| 二类器械首次上市 | 510(k)：审查时钟 90 天，实际多为 4–8 个月 | 注册审评：法定 60 工作日（不含补正），实际 6–12 个月，含体系核查 |
| 三类器械 | PMA：180 天时钟，实际 1–2 年 | 注册审评 + 体系核查 + 临床试验审批，2–3 年常见 |
| 创新无 predicate 产品 | De Novo：120 天时钟，但排队与沟通耗时，实际 1 年左右 | 创新通道：特别审查/优先审批，但**分类界定**常成前置瓶颈 |
| 政府收费 | 高（510(k) $28,653；PMA $636,732） | 极低（注册费数千元级） |
| 主要隐性成本 | 测试 + 顾问 + **产品责任保险** | 时间成本 + 补正沟通 + 临床试验 |

### 10.3 为什么有人更认同美国模式（讲清逻辑，不做价值判断）

三个真实的结构性优势：

1. **predicate 机制让监管成本随时间摊薄**。第一个产品贵，第二个开始便宜。中国每个产品都要独立举证，边际成本不降——这是中国注册费用低但总成本高的根源。
2. **决策分散，不依赖目录更新速度**。美国不必等「分类目录」修订就能让新产品上市（De Novo 逐案解决）；中国无目录条目时，分类界定本身就是一个不确定周期。
3. **上市后责任重于上市前审批**。美国把资源放在召回、MDR、警告信、产品责任诉讼上，企业有持续合规的经济动机。中国上市前把关重、上市后处置手段相对有限。

同时必须讲的三个代价（否则是片面介绍）：

1. **predicate 老化**：靠 1976 年前的老器械做对比，会锁死技术代际。FDA 常年被批评这一点，也是 510(k) 改革讨论的起点。
2. **De Novo 仍是瓶颈**：创新产品"默认 III 类"意味着必须先证明自己能降级，对小公司不友好。
3. **诉讼成本外部化**：产品责任保险对小企业是实质门槛，这部分成本不在注册费里，但真实存在。

## 十一、常见误区（答错率高，逐条记）

| 误区 | 事实 |
|---|---|
| 「FDA 认证 / FDA 批准公司」 | FDA 不发"认证"。510(k) 的结论是 **SE 信函**（实质等同），PMA 是 **PMA 批准令**，企业注册只是登记。没有"FDA 认证工厂"这回事。 |
| 「有 CE 就能进美国」 | 不能。欧盟 MDR 与 FDA 是两套体系，互不承认。 |
| 「510(k) 是审批」 | 法律性质是**上市前通告**（premarket notification），FDA 的许可是"不反对上市"，不是"批准产品"。 |
| 「拿到 510(k) 就可以随便改」 | 设计、材料、适应证重大变化需新提交。企业自行判断，判断错的后果是 adulterated/misbranded。 |
| 「QSR 还是现行」 | QSR 已于 **2026-02-02 废止**，现行是 QMSR。凡 2026 年 2 月前写的资料都会说 QSR，引用前必须核对。 |
| 「三类器械都要做临床试验」 | 不必然。PMA 需要"有效性的有效科学证据"，可来自既有文献、境外数据、替代终点，不等于必须做新 RCT。 |
| 「美国也有注册证有效期」 | 510(k) 与 PMA **无到期日**，靠持续合规维持；但每年要交注册费、做年度报告。中国注册证 5 年有效需延续。 |
| 「小企业折扣自动享受」 | 不自动。须提前 ≥60 天提交小企业认定材料，拿到 SBD 号；无号不退款。 |

### 13.3 三类最容易答错的「名字像、实质不同」

1. **De Novo ≠ 一条程序**。狭义 De Novo 是 (f)(2) 请求（120 天）；(f)(3) 是重新分类请愿（可到 210 天，含 panel）。两者主体、时限、法律效果都不同。
2. **CFG ≠ 出口许可证**。CFG 证明的是「该产品在美国合法」，前提是已注册列名 + 已 clearance/approved/exempt。没在 FDA 注册列名的产品根本拿不到。
3. **PCCP ≠ 变更管理的替代品**。它只覆盖「本来就要报批」的变更；不需要报批的变更走 QMSR，不进 PCCP。
